## Run Locally

### Prerequisites
- Node.js (LTS recommended)
- npm

### Setup

```bash
git clone https://github.com/Divyanshu8595/divyanshupro.git
cd divyanshupro
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Production Build

```bash
npm run build
npm run start
```
